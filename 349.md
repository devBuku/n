Intersection of Two Arrays
### Question
Given two integer arrays nums1 and nums2, return an array of their intersection. Each element in the result must be unique and you may return the result in any order.

 

Example 1:

Input: nums1 = [1,2,2,1], nums2 = [2,2]
Output: [2]

Example 2:

Input: nums1 = [4,9,5], nums2 = [9,4,9,8,4]
Output: [9,4]
Explanation: [4,9] is also accepted.

 

**Constraints:**

- 1 <= nums1.length, nums2.length <= 1000
- 0 <= nums1[i], nums2[i] <= 1000

My Approach
1. creating a map <element, frequency> of the first array
2. creating a set of the second array to remove duplicate entry of elements from second array and also finding common element in the same step
3. creating a new array 'ans' to return
```ts
function intersection(nums1: number[], nums2: number[]): number[] {
	let map = new Map<number, number>();
	let set = new Set<number>();
	let ans = [];
	for (let i = 0; i < nums1.length; i++) {
		if (map.has(nums1[i])) {
			map.set(nums1[i], map.get(nums1[i] + 1))
		} else {
			map.set(nums1[i], 1)
		}
	}

	// to remove duplicate elements and finding common element
	for (let i = 0; i < nums2.length; i++) {
		if (map.has(nums2[i])) {
			set.add(nums2[i])
		}
	}
	for (let val of set) {
		ans.push(val);
	}

	return ans;
};
```

Video Approach
1. Create a set of first array
2. for the nums2 array check
	1. if the element exists in the set
	2. if the element already exists in the ans array
```ts
function intersection(nums1: number[], nums2: number[]): number[] {
    let set = new Set(nums1);
    let ans = [];
    for (let i = 0; i < nums2.length; i++) {
        if (set.has(nums2[i]) && !(ans.includes(nums2[i]))) {
            ans.push(nums2[i]);
        }
    }
    return ans;
};
```
