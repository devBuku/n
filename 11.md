Container With Most Water

### Question
You are given an integer array height of length n. There are n vertical lines drawn such that the two endpoints of the ith line are (i, 0) and (i, height[i]).

Find two lines that together with the x-axis form a container, such that the container contains the most water.

Return the maximum amount of water a container can store.

Notice that you may not slant the container.
![[container_with_most_water_question.png]]

**Constraints:**

    n == height.length
    2 <= n <= 105
    0 <= height[i] <= 104

### Approach: Two pointers
 - Set one pointer to the left and one to the right of the array.
 - Always move the pointer that points to the lower line.
 - Width is the difference b/w index of start and end point
```c++
class Solution {
public:
    int maxArea(vector<int>& height) {
        int st = 0;
        int currHeight = 0;
        int currArea = 0;
        int ans = 0;
        int end = height.size() - 1;
        int width = 0;
        while (st < end) {
            width = end - st;
            if (height[end] > height[st]) {
                currHeight = height[st];
                st++;
            } else {
                currHeight = height[end];
                end--;
            }
            currArea = width * currHeight;
            ans = max(ans, currArea);
        }
        return ans;
    }
};
```
