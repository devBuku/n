# My Approach
### MyHashSet Using Singly Linked List

## 1. Problem Understanding

Implement a Set that supports three operations:

- `add(key)` – Insert a key if it doesn't already exist.
- `remove(key)` – Remove a key if it exists.
- `contains(key)` – Check whether a key exists.

**Important:** A Set stores only unique elements. Duplicate values are not allowed.

For this exercise, we are implementing the Set using a Singly Linked List instead of a Hash Table.

---

## 2. Node Structure

```ts
type Node<T> = {
    value: T;
    next?: Node<T>;
};
```

Each node contains:

- `value`: The actual data.
- `next`: Reference to the next node.

Example:

```text
head
 |
 v
10 -> 20 -> 30 -> undefined
              ^
              |
             tail
```

We maintain two pointers:

- `head`: Points to the first node.
- `tail`: Points to the last node.

We also maintain `length` to track the number of elements.

---

## 3. Implementation

```ts
type Node<T> = {
    value: T,
    next?: Node<T>
}

class MyHashSet<T> {
    public length: number;
    private head?: Node<T>
    private tail?: Node<T>

    constructor() {
        this.length = 0;
        this.head = this.tail = undefined;
    }

    add(key: number): void {
        if (this.contains(key)) return;

        const node = { value: key } as Node<T>;
        this.length++;

        if (!this.tail) {
            this.tail = this.head = node;
            return;
        }

        this.tail.next = node;
        this.tail = this.tail.next;
        return;
    }

    remove(key: number): void {
        if (!this.head) return;

        let current = this.head;
        let prev: Node<T> | undefined = undefined;

        while (current) {
            if (current.value === key) {
                if (!prev) {
                    this.head = current.next;
                } else {
                    prev.next = current.next;
                }

                if (current === this.tail) {
                    this.tail = prev;
                }

                current.next = undefined;
                this.length--;
                return;
            }

            prev = current;
            current = current.next;
        }
    }

    contains(key: number): boolean {
        if (!this.head) return false;

        let current = this.head;

        while (current) {
            if (current.value === key) {
                return true;
            }

            current = current.next;
        }

        return false;
    }
}
```

## 4. Understanding Each Operation

### A. add(key)

**Goal:** Insert a new node at the end of the linked list.

Steps:

1. Check whether the key already exists using `contains()`.
2. If it exists, return without inserting.
3. Create a new node.
4. Increase `length`.
5. If the list is empty, make the new node both `head` and `tail`.
6. Otherwise, connect the current tail to the new node.
7. Update the tail.

Example:

Before:

```text
10 -> 20 -> undefined
      ^
     tail
```

Add `30`.

```ts
this.tail.next = node;
this.tail = this.tail.next;
```

After:

```text
10 -> 20 -> 30 -> undefined
           ^
          tail
```

**Remember:** Always update the tail after inserting a new node.

### B. remove(key)

**Goal:** Find the node and disconnect it from the linked list.

We use two pointers:

- `current`: Node currently being examined.
- `prev`: Previous node.

Initially:

```ts
let current = this.head;
let prev: Node<T> | undefined = undefined;
```

We traverse using:

```ts
while (current) {
    // Check and remove
    prev = current;
    current = current.next;
}
```

There are three important deletion cases.

#### Case 1: Removing the head

Before:

```text
head
 |
 v
10 -> 20 -> 30
```

Remove `10`.

```ts
this.head = current.next;
```

After:

```text
head
 |
 v
20 -> 30
```

Since `prev` is undefined, we know that `current` is the head.

#### Case 2: Removing a middle node

Before:

```text
10 -> 20 -> 30
```

Remove `20`.

```ts
prev.next = current.next;
```

After:

```text
10 ------> 30
```

The previous node now points directly to the next node, bypassing the node being removed.

#### Case 3: Removing the tail

Before:

```text
10 -> 20 -> 30
           ^
          tail
```

Remove `30`.

```ts
if (current === this.tail) {
    this.tail = prev;
}
```

After:

```text
10 -> 20 -> undefined
      ^
     tail
```

**Important:** Updating `prev.next` alone is not enough. You must also update the tail.

#### Cleanup and length update

```ts
current.next = undefined;
this.length--;
return;
```

- `current.next = undefined`: Disconnects the removed node from its successor. This is cleanup, not strictly required for removal.
- `this.length--`: Decreases the number of elements.
- `return`: Stops the method immediately after successful deletion.

**Remember:** If the last remaining node is removed, both `head` and `tail` must become undefined.

### C. contains(key)

**Goal:** Traverse the linked list and check whether the key exists.

```ts
let current = this.head;

while (current) {
    if (current.value === key) {
        return true;
    }

    current = current.next;
}

return false;
```

Steps:

1. Start from the head.
2. Compare the current node's value with the key.
3. If found, return `true`.
4. Otherwise, move to the next node.
5. If we reach the end (`undefined`), return `false`.

## 5. Mistakes I Made While Solving

These are the mistakes to remember when revisiting this problem.

### Mistake 1: Using `=` instead of `===`

Incorrect:

```ts
if (current = this.tail)
```

Correct:

```ts
if (current === this.tail)
```

- `=` means assignment.
- `===` means strict equality comparison.

Always double-check comparison operators.

### Mistake 2: Forgetting to update the tail

When deleting the last node:

```ts
prev.next = current.next;
```

This disconnects the node from the list, but the tail might still point to the removed node.

Always remember:

```ts
if (current === this.tail) {
    this.tail = prev;
}
```

### Mistake 3: Confusing reference movement with pointer modification

These statements do different things:

```ts
current = current.next;
```

Moves the `current` variable to another node.

```ts
current.next = undefined;
```

Modifies the current node's next pointer.

```ts
prev.next = current.next;
```

Changes the previous node's next pointer, bypassing the current node.

### Mistake 4: Forgetting `return` after successful deletion

Once we find and remove the node, we should immediately return.

```ts
this.length--;
return;
```

Otherwise, traversal could continue unnecessarily.

Remember: `return` exits the entire function, not just the `if` block.

### Mistake 5: Using `null` when the value is `undefined`

Our node definition uses:

```ts
next?: Node<T>
```

Therefore, when there is no next node, its value is `undefined`.

Use:

```ts
while (current)
```

Instead of:

```ts
while (current !== null)
```

### Mistake 6: Forgetting duplicate prevention

A Set must contain unique elements.

```ts
if (this.contains(key)) return;
```

Always check for duplicates before inserting.

### Mistake 7: Incorrect return type in contains()

Incorrect:

```ts
if (!this.head) return;
```

Correct:

```ts
if (!this.head) return false;
```

A method declared to return `boolean` must return a boolean on every execution path.

## 6. Edge Cases to Test

| Scenario | Expected behavior |
|---|---|
| Add to empty list | Head and tail point to new node |
| Add duplicate | No insertion |
| Remove from empty list | No change |
| Remove head | Head moves to next node |
| Remove middle | Previous node skips current |
| Remove tail | Tail moves to previous node |
| Remove only node | Head and tail become undefined |
| Remove nonexistent key | No change |
| Contains existing key | true |
| Contains missing key | false |

Example:

```ts
const set = new MyHashSet<number>();

set.add(10);
set.add(20);
set.add(30);
set.add(20); // Duplicate

set.remove(30); // Remove tail
set.remove(10); // Remove head
set.remove(20); // Remove last remaining node

console.log(set.length); // 0
console.log(set.contains(20)); // false
```

## 7. Time and Space Complexity

Since we are using a Singly Linked List, we need to traverse the list to find elements.

| Operation | Time Complexity |
|---|---|
| add() | O(n) |
| remove() | O(n) |
| contains() | O(n) |

Space Complexity: O(n), where n is the number of stored elements.

**Why is add() O(n)?**

Because we call `contains()` before insertion to prevent duplicates.

The actual insertion at the tail is O(1), but duplicate checking takes O(n).

---

## 8. Important Interview Concept

This implementation is a Set backed by a Singly Linked List, not a true HashSet.

A real HashSet uses:

1. A hash function to convert a key into an index.
2. An array of buckets.
3. Collision handling when multiple keys map to the same bucket.

Average time complexity of a properly implemented HashSet:

| Operation  | Average |
| ---------- | ------- |
| add()      | O(1)    |
| remove()   | O(1)    |
| contains() | O(1)    |


**The most important invariant:**

> If the list is empty, `head` and `tail` must both be undefined. If the list is non-empty, `head` points to the first node and `tail` points to the last node.
