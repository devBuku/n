 Pow(x, n)

### Question
Implement pow(x, n), which calculates x raised to the power n (i.e., xn).


Example 1:

Input: x = 2.00000, n = 10
Output: 1024.00000

Example 2:

Input: x = 2.10000, n = 3
Output: 9.26100

Example 3:

Input: x = 2.00000, n = -2
Output: 0.25000
Explanation: 2-2 = 1/22 = 1/4 = 0.25

 

**Constraints:**
- -100.0 < x < 100.0
- -231 <= n <= 231-1
- n is an integer.
- Either x is not zero or n > 0.
- -104 <= xn <= 104


## Approach: Binary Exponentiation

### Why?

A simple approach is to multiply `x` by itself `n` times.

- **Time:** \(O(n)\)
- The exponent can be as large as \(2^{31}-1\), making this approach too slow.

Instead, use **Binary Exponentiation**, which calculates the power in \(O(\log |n|)\) time.

### Key idea

Instead of multiplying `x` repeatedly, square the base to calculate larger powers quickly.

For an even exponent:

\[
x^n = (x^2)^{n/2}
\]

For an odd exponent:

\[
x^n = x \cdot (x^2)^{(n-1)/2}
\]

Each iteration halves the exponent.

### Algorithm

Maintain two variables:

- `base`: The current power of `x`.
- `result`: The answer accumulated so far.

1. Convert `n` to `long long` to handle the minimum 32-bit integer safely.
2. If `n` is negative, replace `x` with `1 / x` and make `n` positive.
3. If the exponent is odd, multiply `result` by `base`.
4. Square `base`.
5. Divide the exponent by `2`.
6. Repeat until the exponent becomes `0`.

### Code (C++)

```cpp
class Solution {
public:
    double myPow(double x, int n) {

        long binForm = n;

        if (n < 0) {
            x = 1 / x;
            binForm = -binForm;
        }

        double ans = 1;

        while (binForm > 0) {
            if (binForm % 2 != 0) {
                ans = ans * x;
                x *= x;
            } else {
                x *= x;
            }

            binForm /= 2;
        }

        return ans;
    }
};
```

## Dry Run

For `x = 2, n = 10`:

| Exponent | Base | Result | Action                    |
| -------: | ---: | -----: | ------------------------- |
|       10 |    2 |      1 | Even: skip multiplication |
|        5 |    4 |      1 | Odd: result = 1 * 4       |
|        2 |   16 |      4 | Even: skip multiplication |
|        1 |  256 |      4 | Odd: result = 4 * 256     |
|        0 |    — |   1024 | Stop                      |

**Answer:** `1024`

## Why does it work?

The binary representation of `10` is `1010`.

- If the exponent is odd, its lowest binary bit is `1`, so multiply the result by the current base.
- Dividing the exponent by `2` shifts its binary representation one bit to the right.
- Squaring the base moves to the next power: \(x, x^2, x^4, x^8, \ldots\)

This allows us to calculate the answer without performing `n` multiplications.

## Important Edge Cases

### Negative exponent

\[
x^{-n} = \frac{1}{x^n}
\]

Take the reciprocal of `x` and convert the exponent to positive.

### Integer overflow

The minimum 32-bit signed integer is \(-2^{31}\). Its positive counterpart \(2^{31}\) cannot fit in an `int`.

Therefore, convert `n` to `long long` **before negating it**.

## Complexity

- **Time:** \(O(\log |n|)\) — the exponent is halved in every iteration.
- **Space:** \(O(1)\) — only a fixed number of variables are used.

## What to Remember

- **Binary Exponentiation:** Square the base and halve the exponent.
- **Odd exponent:** Multiply the current base into the result.
- **Negative exponent:** Take the reciprocal of the base.
- **Integer edge case:** Convert to `long long` before negating `n`.
