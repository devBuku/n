Majority Element

### Question
Given an array nums of size n, return the majority element.

The majority element is the element that appears ==more than ⌊n / 2⌋ times.== You may assume that the majority element always exists in the array.

 

Example 1:

Input: nums = [3,2,3]
Output: 3

Example 2:

Input: nums = [2,2,1,1,1,2,2]
Output: 2


### Approach: Moore's Voting Algorithm

- `freq` keeps track of the current candidate's frequency.
- `ans` stores the current majority candidate.
- If `freq == 0`, choose the current element as the new candidate.
- If the current element matches `ans`, increment `freq`; otherwise, decrement it.
- **Since the majority element appears more than `n / 2` times, it cannot be cancelled out by all the other elements.**

```c++
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        int freq = 0;
        int ans = 0;
        for (auto val : nums) {
            if (freq == 0) {
                ans = val;
            }

            if (ans == val) {
                freq++;
            } else {
                freq--;
            }
        }
        return ans;
    }
};
```
#### Complexity
- Time: O(n) — traverse the array once.
- Space: O(1) — use only two variables.

#### The algorithm relies on the problem's guarantee that a majority element always exists. Without that guarantee, a verification pass would be needed.
