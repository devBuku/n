
# Group Anagrams


## My Approach

1. For each `str` in `strs`:
2. Sort the string and use the sorted string as the key to check the hashmap.
   3. If the sorted string is not in the hashmap:
      - Create a new array containing the current string and push it into `ans`.
      - Store the index of that array in the hashmap.
      - `<sorted string, 2D ans array index>`
   4. If the sorted string is already available in the hashmap:
      - Get the index from the hashmap.
      - Add the current string to that index in `ans`.

## Important Concepts

### 1. String.prototype.sort()

Strings are immutable primitive values in JavaScript/TypeScript. They don't have a `.sort()` method.

**Correct approach:** Convert the string into an array, sort it, and join it back.

```ts
const sortedStr = str.split('').sort().join('');
````

### 2. Array.push() returns a number

`.push()` mutates the original array and returns its new length, not the array itself.

```
// Correct
map.get(sortedStr)!.push(str);
```

Avoid chaining `.push()` calls because the first `.push()` returns a number.

### 3. Understanding ans.length

```
const ans: string[][] = [["eat", "tea"], ["tan"]];

console.log(ans.length); // 2
```

`ans.length` counts the top-level elements (groups), not the individual strings inside each group.

### 4. Map and Array Index Tracking

When creating a new group:

1. Push the new sub-array into `ans`.
2. Store its index in the map using `ans.length - 1`.

Remember: `ans.length - 1` gives the last valid index only after pushing the new array.

## My Implementation

```ts
function groupAnagrams(strs: string[]): string[][] {
    let map = new Map<string, number>();
    let ans: string[][] = [];

    for (let str of strs) {
        let sortedStr = str.split('').sort().join('');

        if (map.has(sortedStr)) {
            ans[map.get(sortedStr)!].push(str);
        }
        else {
            ans.push([str]);
            map.set(sortedStr, ans.length - 1);
        }
    }

    return ans;
};
```

## Alternative Approach: Store Array References

Instead of storing the index of each group, we can directly store a reference to the group array in the map.

```ts
function groupAnagrams(strs: string[]): string[][] {
    const map = new Map<string, string[]>();

    for (const str of strs) {
        const sortedStr = str.split('').sort().join('');

        if (!map.has(sortedStr)) {
            map.set(sortedStr, []);
        }

        map.get(sortedStr)!.push(str);
    }

    return Array.from(map.values());
}
```

Why does this work?

- Arrays are objects in JavaScript.
- Objects are stored and passed around using references.
- The map stores a reference to each group array.
- Calling `.push()` through that reference modifies the same array stored inside the map.
- `Array.from(map.values())` collects all the groups into the final 2D array.

## Complexity Analysis

Let:

- `N` = Number of strings.
- `K` = Maximum length of a string.

| Complexity | Value          | Reason                                      |
| ---------- | -------------- | ------------------------------------------- |
| Time       | O(N × K log K) | Sorting each string takes O(K log K).       |
| Space      | O(N × K)       | Storing the grouped strings and their keys. |


### Technical corrections / notes

- **Your implementation is correct.** Both the index-tracking and direct-reference approaches work.
- `map.get(sortedStr)!` uses TypeScript's non-null assertion operator. It tells TypeScript that the value won't be `undefined`. Your preceding `map.has()` check guarantees that in this implementation.
- The space complexity is an upper bound that includes the output and map keys. Sorting may also require temporary space.
- One small distinction: JavaScript's `.sort()` sorts array elements as strings by default. That's exactly what we need when sorting individual characters here.

**Interview takeaway:** The key insight is that anagrams produce the same sorted string. Use that sorted string as a common key to group them.
